# Beverage Sales Analysis

## Overview

Analysis of 8,999,910 sales line items across 3 million orders in a German beverage distribution dataset from 2021 to 2023. The project examines how revenue varies by product category, customer type, region, and month. It also compares average units per line across B2B discount bands and checks whether February’s lower monthly revenue persists after adjusting for calendar days.

## Tools Used

- **SQLite / DB Browser for SQLite** — data validation, SQL analysis, and summary exports
- **Tableau Public** — interactive dashboard for revenue trends, regional performance, and discount-band comparisons
